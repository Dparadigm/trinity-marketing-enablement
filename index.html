1. Why this matters

  • Accept what matters this week.
  • Write only after a brief is Accepted.
  • Draft ≠ done — human gate before publish.
  • Friday: did that work move the funnel?
Lanes: CMO decides → Copywriter drafts → Marketing ships → funnel decides next week.

3. Synthesis Brief

Each Monday the CMO agent rolls the week’s marketing reports into one Synthesis Brief so Marketing can decide what moves the funnel: more MQLs → more appointments → more closed business.

  • Force-ranks the week (including THE ONE THING)
  • Flags measurement contradictions
  • Shows projected outcomes with the math
  • Rolls up capacity so you don’t re-read every upstream report

We’re co-designing improvements with Marketing (Friday close-outs; clearer decision vs execution vs technical vs signal). Use the co-design brief for that conversation; use the latest Monday brief as the live example.

  • Co-design brief (Sep 25 meeting)

4. Weekly rhythm

WhenDo
Monday · 30–45 min Open Synthesis Brief → Accept / Defer / Kill → lock THE ONE THING → owner + due day + funnel outcome
Mid-week · ~15 min Execute Accepts. Copywriter drafts when needed. Human-gate before publish.
Friday · ~15 min Shipped? Funnel move (traffic / clicks / CTR / leads)? Keep, change, or Kill.
Done = published or intentionally killed — not “drafted.”

5. Accept / Defer / Kill

DecisionMeaningNeed
AcceptDo it this weekOwner + due day + funnel outcome

KillWrong or staleOne-line why
  • No Accept without a funnel outcome.
  • THE ONE THING done by Wednesday when possible.
  • Carry-overs > 2 weeks → Kill or re-scope.
  • Not in the brief + not an emergency → waits until Monday.
